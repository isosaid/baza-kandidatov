# База кандидатов

Внутренняя платформа подбора для холдинга ООО «Авесто Групп»: резюме
с Диска Битрикс24 → структурированная база → шорт-лист под критерии позиции.

Это один файл `index.html`. Сервер, сборка и установка не нужны: разбор
резюме идёт прямо в браузере, база хранится в его IndexedDB, наружу
ничего не уходит.

```
index.html      вся платформа
lib/            локальные копии библиотек чтения PDF и DOCX (для портала без интернета)
tests/          автотесты в настоящем Chromium — см. tests/README.md
```

Интерфейс двуязычный: русский и таджикский.

## 1. Быстрый старт (без Битрикса)

Откройте `index.html` двойным щелчком. На вкладке «Загрузка резюме»
перетащите папку с резюме **или архив `.zip`, скачанный с Диска Битрикс24**
(выделите папку «Резюме» на Диске и нажмите «Скачать» — портал отдаст
один архив со всей структурой). Имена папок-направлений внутри архива
станут позициями кандидатов. Затем
на вкладке «Поиск кандидатов» опишите вакансию обычным текстом, например:

> Нужен главный бухгалтер. Опыт от 5 лет, обязательно 1С и МСФО,
> высшее образование, Душанбе.

Кнопка «Разобрать запрос» сама заполнит поля: позицию, минимальный опыт,
образование, город, язык и навыки. Навыки попадают в «желательные» —
стрелкой ↑ переводите нужные в «обязательные», они отсеивают кандидатов.

В шорт-листе ссылка «Как рассчитан процент?» раскрывает расчёт по каждому
критерию с его весом. Веса меняются в настройках: критерий, который вы
не задали в поиске, в расчёте не участвует.

## 2. Работа без интернета

По умолчанию библиотеки чтения PDF и DOCX берутся с cdnjs.cloudflare.com.
Эти копии уже лежат в папке `lib/` этого репозитория — переносите её
вместе с `index.html`, и интернет не понадобится. Версии и порядок
обновления описаны в `lib/VERSIONS.md`.

Платформа сначала пробует CDN, затем `lib/`. Если не нашлось ни там, ни там —
на вкладке загрузки появится красное предупреждение с именами нужных файлов.

## 3. Размещение внутри Битрикс24 (рекомендуемый путь)

1. Портал → **Маркет → Локальные приложения → Добавить**.
2. Тип — **Приложение с интерфейсом**. Загрузите `index.html`
   или укажите адрес, если файл лежит на вашем хостинге.
3. Права приложения: `disk`, `crm`, `user`.
4. Откройте приложение изнутри портала. Платформа определит это сама
   (на вкладке «Битрикс24» появится зелёная плашка) и будет ходить в REST
   через `BX24.callMethod` — вебхук не нужен, CORS не мешает.

## 4. Подключение по входящему вебхуку (запасной путь)

1. Портал → **Разработчикам → Другое → Входящий вебхук**. Права: `disk`, `crm`.
2. Скопируйте адрес вида `https://crm.avesto.tj/rest/1/xxxxxxxxxxxx/`
   на вкладку «Битрикс24» платформы.
3. Нажмите «Проверить связь».

Этот путь работает, только если портал отдаёт CORS-заголовки для домена,
с которого открыта страница. При ошибке CORS используйте п. 3.

## 5. Какую папку синхронизировать

ID папки в интерфейсе Битрикса нигде не показывается, поэтому искать его
руками не нужно. На вкладке «Битрикс24» нажмите **«Выбрать на Диске»** —
платформа покажет хранилища (Мой Диск, Общий диск, диски групп), дальше
кликами дойдите до нужной папки и нажмите **«Выбрать эту папку»**.
ID подставится в поле сам.

Публичная ссылка вида `https://crm.avesto.tj/folder/hmyufr2…` для этого
не годится: это ссылка для людей, API у неё нет.

### Как раскладывать резюме на Диске

Платформа берёт название позиции из имени папки, в которой лежит файл:

```
Резюме/                 ← эту папку выбираете при синхронизации
  Бухгалтер/
    Рахимова.pdf        → позиция «Бухгалтер»
    Курбонов.docx       → позиция «Бухгалтер»
  Юрист/
    Назарова.pdf        → позиция «Юрист»
```

Галочка «включая вложенные папки» обходит всё дерево. Файлы, лежащие
прямо в выбранной папке без подпапки, попадут в базу без позиции —
её можно проставить вручную в карточке.

Повторная синхронизация дубликатов не создаёт: файл опознаётся
по его ID на Диске.

## 6. Что уходит наружу

Кнопка «Скопировать обезличенный шорт-лист» выгружает кандидатов под кодами
`K-001`, `K-002`… без ФИО, телефона и почты. Сопоставление кода с личными
данными остаётся только в базе платформы.

## 7. Ограничения этой версии

* Сканы и фотографии резюме без текстового слоя распознать нельзя — такие
  файлы попадают в базу помеченными, поля заполняются вручную в карточке.
* Формат `.doc` (старый Word) читается грубо, извлекается не весь текст.
  Попросите присылать `.docx` или PDF.
* База живёт в браузере конкретного компьютера. Для переноса —
  «Настройки → Выгрузить базу в файл» и загрузка на другом компьютере.
* Разбор свободного запроса — правила и словарь, а не языковая модель.
  Он уверенно берёт опыт, образование, город, язык и навыки из словаря;
  требования, которых в словаре нет («опыт с китайскими поставщиками»),
  он не увидит — добавьте их в словарь или впишите в поля руками.

## 8. Словарь навыков

Вкладка «Настройки → Словарь навыков». По одному навыку в строке,
синонимы через `=`:

```
1С = 1C = 1С:Предприятие = 1С Бухгалтерия
МСФО = IFRS
```

Поиск учитывает русские окончания (`бухгалтерский учёт` находит
`бухгалтерского учета`) и таджикские буквы (`ӣ ҳ ҷ ғ қ ӯ`).
Словарь применяется при следующей загрузке резюме.

## 9. Что есть в платформе

| Раздел | Что делает |
|---|---|
| Поиск кандидатов | свободный запрос → критерии, шорт-лист с процентом соответствия и расчётом по критериям, доп. фильтры (ФИО, пол, опыт до, категория, доп. требования), сортировка, вердикты «подходит / не подходит» |
| Все резюме | вся база с фильтрами по категории, позиции, городу, образованию и статусу; показ по 50 записей; экспорт CSV |
| Избранное | сохранённые шорт-листы по вакансиям и история поисков с повторным применением критериев |
| Карточка кандидата | все разобранные поля с ручной правкой, оценка соответствия, два слоя данных (оригинал на Диске и разобранный текст) |
| Загрузка резюме | файлы, папки и zip-архивы; сканы без текста помечаются |
| Администрирование | подключение к Битрикс24, выбор папки на Диске, автосинхронизация по интервалу, журнал синхронизаций, веса критериев, словарь навыков, пользователи и роли, управление данными |

### Категории должностей

Каждому резюме автоматически проставляется одна из 13 категорий
(бухгалтерия и финансы, производственные и технические, юриспруденция,
IT, HR, закупки и логистика, маркетинг и продажи, проектная работа,
административные, транспорт, топ-менеджмент, начало карьеры,
безопасность). Определение идёт по должности, навыкам и тексту резюме;
в карточке категорию можно поменять вручную.

## 10. Проверки

Платформа покрыта автотестами, которые гоняют настоящий `index.html`
в headless Chromium: разбор 10 резюме разной структуры, 14 проверок
на ложные срабатывания, 21 проверка разбора свободного запроса
10 проверок обозревателя Диска и синхронизации на поддельном портале
и 17 проверок категорий, пола, переезда, zip-архива, избранного и фильтров.
Как запустить — в `tests/README.md`.
