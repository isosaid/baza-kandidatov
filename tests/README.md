# Проверки

Тесты гоняют настоящее приложение в headless Chromium через Playwright —
не копию логики, а сам `index.html`.

## Запуск

```bash
npm install playwright
npx playwright install chromium     # если браузер ещё не установлен
python3 mk_resumes.py               # генерирует резюме и эталон
node test_parser.js                 # разбор резюме: поля, навыки, языки
node test_edge.js                   # ловушки и ложные срабатывания
node test_query.js                  # разбор свободного описания вакансии
node test_bitrix.js                 # обозреватель Диска и синхронизация
node test_features.js               # категории, пол, zip, избранное, фильтры
node test_storages.js               # поиск личного диска на портале с сотнями хранилищ
```

Проверка общей базы в Drive идёт без Chromium — на jsdom:

```bash
npm install jsdom fake-indexeddb
node tests/test_gdrive.js           # сохранение в Drive, ссылка для коллег, опрос обновлений
```

`mk_resumes.py` требует `reportlab` и `python-docx`, а также шрифт
DejaVu Sans (в Debian/Ubuntu — пакет `fonts-dejavu`).

## Что чем проверяется

**`test_parser.js`** — 10 сгенерированных резюме разной структуры: русские
и таджикские, PDF, DOCX, TXT и один скан без текстового слоя. Сверяет ФИО,
телефон, почту, город, год рождения, стаж, образование, навыки и языки
с эталоном из `mk_resumes.py`. Ожидаемый результат — 63/63 полей,
навыки и языки 100% без лишних срабатываний.

**`test_edge.js`** — 14 проверок на ошибки, которые уже случались и не должны
вернуться: фамилия «Солиев» не даёт «высшее» из-за подстроки «оли»,
«кассационная жалоба» не считается навыком «Касса», дата рождения не попадает
в телефоны, годы учёбы не засчитываются в стаж, падежи распознаются,
таджикский изафет «Донишгоҳи давлатӣ» даёт высшее.

**`test_query.js`** — 21 проверка разбора свободного описания вакансии
на шести запросах, включая таджикский.

**`test_bitrix.js`** — 10 проверок на поддельном портале Битрикс24 со
структурой «Мой Диск → Резюме → направления → файлы»: обход хранилищ
и папок, подстановка ID выбранной папки, загрузка только резюме
(картинки пропускаются), позиция из имени папки-направления и отсутствие
дубликатов при повторной синхронизации. Настоящий портал для прогона
не нужен — `window.BX24` подменяется заглушкой.

**`test_features.js`** — 17 проверок того, что добавлено по ТЗ: 13 категорий
должностей на 10 типовых вакансиях, определение пола по фамилии и отчеству,
готовность к переезду, распаковка zip-архива с Диска с сохранением
структуры папок, фильтры по категории и полу, вердикты «подходит /
не подходит», сохранение шорт-листа в избранное и запись в историю
поисков, добавление пользователя и интервал автосинхронизации.

**`test_storages.js`** — 8 проверок на портале с 800 хранилищами, где личный
диск нужного сотрудника лежит на 300-й позиции. REST отдаёт хранилища по 50
за раз, поэтому личный диск ищется фильтром по текущему пользователю,
а при отсутствии результата — постраничным перебором. Отдельно проверяется
портал, который фильтр молча игнорирует и отдаёт первые 50 записей подряд:
ответ на фильтр перепроверяется по содержимому, иначе чужой диск
принимается за свой.

## Про кириллицу в путях

Playwright не передаёт в форму файлы, путь которых содержит кириллицу,
и делает это молча — форма просто остаётся пустой. Поэтому `mk_resumes.py`
кладёт ASCII-копии в `stage/`, а разбор ФИО из кириллического имени файла
проверяется отдельным вызовом в конце `test_parser.js`.
